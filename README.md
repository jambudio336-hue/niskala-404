## 📌 Overview

**NISKALA-404** is a high-performance, dark-web themed full-stack web application and Progressive Web App (PWA). Engineered with absolute security, local-first API key hashing (`localStorage`), multi-model switching via OpenRouter, and a fully interactive cyberpunk dashboard complete with an animated anime katana girl aesthetic.

---

## ✨ Key Features

- 🔐 **Secure Local API Key Gateway:** Users input their personal OpenRouter API key, which is securely stored and hashed locally.
- 👻 **Anime Phantom Dashboard:** Cyberpunk dark-web UI featuring anime katana action visuals and quick module launchers.
- 🤖 **Mr. Kiplay AI Chat:** Unrestricted, jailbroken AI core with zero content filters, file/image upload analysis, copy-to-clipboard buttons, and custom output footers (`By.Mr.Kiplay`).
- 🎙️ **Jarvis Voice Intelligence:** Real-time voice interaction with audio synthesis and neural speech recognition.
- 🎯 **OSINT Suite:** Google Dork generator with direct Google redirect links, website vulnerability tester, social engineering tools, and data registry/leak checkers.
- 🛡️ **Red Team & Hacking Manual:** Comprehensive guide on penetration testing methodologies, red/white/grey team tactics, and direct GitHub exploit tools (`sqlmap`, `sherlock`).

---

## 🛠️ Tech Stack

- **Frontend & UI:** HTML5, CSS3, Tailwind CSS (Dark Mode optimized), JavaScript (ES6+).
- **Icons & Fonts:** FontAwesome 6, Google Fonts (JetBrains Mono, Orbitron).
- **AI Integration:** OpenRouter API (`openrouter/free`, Claude 3 Opus, GPT-4o, DeepSeek Coder).
- **Architecture:** Full-stack Progressive Web App (PWA) designed for speed, zero server latency, and cross-platform deployment.
